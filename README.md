# cache_data

Generated data used by the dashboards published at
[xadupre.github.io](https://xadupre.github.io/).

The repository is published with GitHub Pages, so files at the repository root
are available under `https://xadupre.github.io/cache_data/`. Data collection
workflows and their source code remain in
[`xadupre/xadupre.github.io`](https://github.com/xadupre/xadupre.github.io).

Files in this repository are generated automatically. Manual edits may be
overwritten by the next collection workflow run.
